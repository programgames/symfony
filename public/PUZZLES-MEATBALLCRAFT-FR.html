Puzzles cachés de MeatballCraft

92 recettes secrètes du pack. Elles n'apparaissent pas dans JEI. Devine les ingrédients, craft-les : le jeu t'accorde alors un game stage et la recette devient visible pour toujours.

Pastille ch.5 pleine : une quête nomme l’objet · pastille ch.5 en pointillé : chapitre déduit, survole-la pour la règle.
Un nom souligné en pointillé est reconstruit depuis l'identifiant de registre.
Dans les recettes : ° = tout équivalent du dictionnaire de minerais convient · ∗ = l'objet exige des données NBT précises, détaillées dans l'explication · un lien = cet ingrédient est lui-même un puzzle.
